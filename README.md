# Todo Manager

Консольный менеджер задач на языке Go. Позволяет добавлять, просматривать,
отмечать выполненными и удалять задачи, а также экспортировать и импортировать
их в форматах JSON и CSV. Данные хранятся в файле `tasks.json`.

## Возможности

- Добавление задачи (`add`)
- Просмотр с фильтрацией: все / выполненные / ожидающие (`list`)
- Отметка задачи выполненной (`complete`)
- Удаление задачи (`delete`)
- Экспорт в CSV или JSON (`export`)
- Импорт из CSV или JSON (`load`)
- Обработка ошибок ввода и файловых операций

## Требования

- Go 1.24+

## Сборка и запуск

```bash
go build -o todo .
./todo <command> [flags]
```

## Команды

| Команда | Флаги | Описание |
|---|---|---|
| `add` | `--desc` | Добавить задачу (флаг обязателен) |
| `list` | `--filter=all/done/pending` | Показать задачи (по умолчанию `all`) |
| `complete` | `--id` | Отметить задачу выполненной |
| `delete` | `--id` | Удалить задачу |
| `export` | `--format=csv/json`, `--out` | Экспорт задач в файл |
| `load` | `--file` | Импорт задач из файла |

## Примеры

```bash
./todo add --desc="Изучить тесты в Go"
# добавлена задача #1: Изучить тесты в Go

./todo add --desc="Написать README"
./todo list --filter=pending
# [1] pending — Изучить тесты в Go
# [2] pending — Написать README

./todo complete --id=1
# completed task #1

./todo list --filter=done
# [1] done — Изучить тесты в Go

./todo export --format=csv --out=tasks.csv
# exported 2 tasks to tasks.csv

./todo load --file=tasks.csv
# loaded 2 tasks from tasks.csv
```

## Структура проекта

```
todo-manager/
├── go.mod
├── main.go                     # CLI: разбор команд и флагов, координация
├── README.md
└── internal/
    ├── todo/
    │   ├── task.go             # структура Task (ID, Description, Done)
    │   └── manager.go          # логика: Add, List, Complete, Delete
    └── storage/
        ├── json_storage.go     # LoadJSON / SaveJSON
        └── csv_storage.go      # LoadCSV / SaveCSV
```

Архитектура построена на разделении ответственности: `main.go` координирует
слои, пакет `todo` содержит предметную логику и ничего не знает о файлах,
пакет `storage` отвечает за хранение и форматы. Зависимости направлены
только в одну сторону: `main → storage → todo`.

## Хранение данных

Основной файл — `tasks.json`:

```json
[
  {"id": 1, "description": "Изучить тесты в Go", "done": false}
]
```

Формат CSV (первая строка — заголовок):

```
id,description,done
1,Изучить тесты в Go,false
```

Команда `load` определяет формат импорта по расширению файла:
`.csv` → CSV, любое другое → JSON.

## Обработка ошибок

- вызов без команды или с неизвестной командой — подсказка `usage` и код выхода 1;
- отсутствие обязательного флага (`--desc`, `--id`, `--out`, `--file`) — сообщение об ошибке и код выхода 1;
- `--id` меньше или равный нулю — сообщение об ошибке и код выхода 1;
- задача с указанным `id` не найдена — сообщение об ошибке и код выхода 1;
- неизвестный формат в `--format` — сообщение об ошибке и код выхода 1;
- синтаксически некорректные флаги (например, `--id=abc`) — обрабатываются пакетом `flag`, код выхода 2;
- первый запуск без `tasks.json` — программа начинает с пустого списка без ошибки;
- импорт из несуществующего файла — импортируется пустой список (согласованное поведение хранилища).

## Ручное тестирование

| Проверка | Ожидаемый результат |
|---|---|
| `./todo` | usage, код выхода 1 |
| `./todo add` (без `--desc`) | `error: --desc is required`, код 1 |
| `./todo add --desc=x --id=abc` | ошибка парсинга флагов, код 2 |
| `./todo complete --id=999` | `task с id 999 не найдена`, код 1 |
| `./todo list --filter=bogus` | показаны все задачи |
| `./todo export --format=xml --out=f.txt` | `error: unknown format "xml"`, код 1 |
| `rm tasks.json && ./todo list` | `no tasks`, без паники |
