# Todo Manager

Консольный менеджер задач на языке Go. Позволяет добавлять, просматривать,
отмечать выполненными и удалять задачи, а также экспортировать и импортировать
их в форматах JSON и CSV. Данные хранятся в файле `tasks.json`.

## Возможности

- Добавление задачи (`add`)
- Просмотр с фильтрацией: все / выполненные / ожидающие (`list`)
- Отметка задачи выполненной (`complete`)
- Удаление задачи (`delete`)
- Экспорт в CSV или JSON (`export`)
- Импорт из CSV или JSON (`load`)
- Обработка ошибок ввода и файловых операций

## Требования

- Go 1.24+

## Сборка и запуск

```bash
go build -o todo .
./todo <command> [flags]
```

## Команды

| Команда | Флаги | Описание |
|---|---|---|
| `add` | `--desc` | Добавить задачу (флаг обязателен) |
| `list` | `--filter=all/done/pending` | Показать задачи (по умолчанию `all`; неизвестное значение — ошибка) |
| `complete` | `--id` | Отметить задачу выполненной |
| `delete` | `--id` | Удалить задачу |
| `export` | `--format=csv/json`, `--out` | Экспорт задач в файл |
| `load` | `--file` | Импорт задач из файла |

## Примеры

```bash
./todo add --desc="Изучить тесты в Go"
# добавлена задача #1: Изучить тесты в Go

./todo add --desc="Написать README"
./todo list --filter=pending
# [1] pending — Изучить тесты в Go
# [2] pending — Написать README

./todo complete --id=1
# completed task #1

./todo list --filter=done
# [1] done — Изучить тесты в Go

./todo export --format=csv --out=tasks.csv
# exported 2 tasks to tasks.csv

./todo load --file=tasks.csv
# загружено 2 задач из tasks.csv, существующие задачи заменены
```

## Структура проекта

```
todo-manager/
├── go.mod
├── main.go                     # CLI: разбор команд и флагов, координация
├── README.md
└── internal/
    ├── todo/
    │   ├── task.go             # структура Task (ID, Description, Done) и валидация (Validate, ValidateTasks)
    │   └── manager.go          # логика: Add, List, Complete, Delete
    └── storage/
        ├── json_storage.go     # LoadJSON / LoadJSONImport / SaveJSON
        └── csv_storage.go      # LoadCSVImport / SaveCSV
```

Архитектура построена на разделении ответственности: `main.go` координирует
слои, пакет `todo` содержит предметную логику и ничего не знает о файлах,
пакет `storage` отвечает за хранение и форматы. Зависимости направлены
только в одну сторону: `main → storage → todo`.

## Хранение данных

Основной файл — `tasks.json`:

```json
[
  {"id": 1, "description": "Изучить тесты в Go", "done": false}
]
```

Формат CSV (первая строка — заголовок):

```
id,description,done
1,Изучить тесты в Go,false
```

Команда `load` определяет формат импорта по расширению файла
(без учёта регистра): `.json` → JSON, `.csv` → CSV. Любое другое
расширение — ошибка «неподдерживаемый формат файла» и код выхода 1.
Если файл импорта не существует, команда `load` выводит ошибку и
завершается с кодом 1, не изменяя `tasks.json`.

Импортируемые данные (JSON и CSV) проходят единую валидацию:
`id` должен быть положительным числом, описание — непустым, ID задач
не должны повторяться. При нарушении выводится ошибка с указанием
проблемной задачи и причину, `tasks.json` не изменяется. JSON-значение
`null` трактуется как пустой список. После успешного импорта команда
сообщает, что существующие задачи заменены импортированными.

Запись файлов (`tasks.json` и экспорт) выполняется атомарно: данные
сначала пишутся во временный файл в том же каталоге, затем файл
переименовывается — при сбое старая версия данных не теряется.

Следующий ID вычисляется как максимум среди ID текущих задач плюс единица.
После удаления задачи с максимальным ID её номер может быть выдан новой
задаче: гарантируется только уникальность ID среди существующих задач —
осознанное решение для локального приложения.

## Обработка ошибок

Все ошибки выводятся в stderr, результаты успешных операций — в stdout.

- вызов без команды или с неизвестной командой — подсказка `usage` и код выхода 1;
- отсутствие обязательного флага (`--desc`, `--id`, `--out`, `--file`) — сообщение об ошибке и код выхода 1;
- `--id` меньше или равный нулю — сообщение об ошибке и код выхода 1;
- лишние позиционные аргументы после флагов — ошибка «неизвестные аргументы: ...» и код выхода 1;
- задача с указанным `id` не найдена — сообщение об ошибке и код выхода 1;
- неизвестный формат в `--format` — сообщение об ошибке и код выхода 1;
- синтаксически некорректные флаги (например, `--id=abc`) — обрабатываются пакетом `flag`, код выхода 2;
- первый запуск без `tasks.json` — программа начинает с пустого списка без ошибки;
- импорт из несуществующего файла — сообщение об ошибке в stderr и код выхода 1, `tasks.json` не изменяется;
- экспорт в основной файл данных `tasks.json` — сообщение об ошибке и код выхода 1;
- неизвестный фильтр в `--filter` (`list`) — сообщение об ошибке с перечислением допустимых значений и код выхода 1;
- неподдерживаемое расширение файла в `--file` (`load`) — сообщение об ошибке и код выхода 1;
- некорректные данные импорта (неположительный `id`, пустое описание, дубликаты `id`) — сообщение об ошибке с указанием задачи и причины, код выхода 1.

## Ручное тестирование

| Проверка | Ожидаемый результат |
|---|---|
| `./todo` | usage, код выхода 1 |
| `./todo add` (без `--desc`) | `error: --desc is required`, код 1 |
| `./todo add --desc=x --id=abc` | ошибка парсинга флагов, код 2 |
| `./todo complete --id=999` | `task с id 999 не найдена`, код 1 |
| `./todo list --filter=bogus` | `error: неизвестный фильтр "bogus": допустимые значения: all, done, pending`, код 1 |
| `./todo load --file=import.txt` | `error: неподдерживаемый формат файла "import.txt": допустимы .json и .csv`, код 1 |
| `./todo load --file=null.json` (содержит `null`) | `загружено 0 задач из null.json, существующие задачи заменены` |
| `./todo export --format=xml --out=f.txt` | `error: unknown format "xml"`, код 1 |
| `rm tasks.json && ./todo list` | `no tasks`, без паники |
| `./todo add --desc="   "` (описание из одних пробелов) | `error: --desc is required`, код 1 |
| `./todo complete 5` (лишний позиционный аргумент) | `error: неизвестные аргументы: 5`, код 1 |
| `./todo load --file=no.json` (файл не существует) | `error: файл импорта "no.json" не найден: ...`, код 1, `tasks.json` не изменяется |
| `./todo load --file=hdr2.csv` (заголовок `id,description` — 2 колонки) | `error: ... строка 1: неверный заголовок CSV: ожидается "id,description,done", получено "id,description"`, код 1 |
| `./todo load --file=short.csv` (строка `1,Задача` — 2 поля) | `error: ... строка 2: ожидается 3 поля, получено 2`, код 1 |
| `./todo load --file=hdr.csv` (заголовок `a,b,c`) | `error: ... строка 1: неверный заголовок CSV: ожидается "id,description,done", получено "a,b,c"`, код 1 |
| `./todo load --file=struct.json` (содержит `{"id": 1}` — объект вместо массива) | `error: не удалось разобрать JSON из "struct.json": ...`, код 1 |
| `./todo load --file=dup.json` (две задачи с `id: 1`) | `error: ... дубликат id 1 (задача 2)`, код 1 |
| `./todo load --file=neg.json` (задача с `id: -1`) | `error: ... id должен быть положительным числом, получено -1`, код 1 |
| `./todo load --file=blank.json` (задача с `description: ""`) | `error: ... описание пустое или состоит только из пробелов`, код 1 |
| `./todo export --out=tasks.json` (также `--out=./tasks.json` и абсолютный путь) | `error: экспорт в основной файл данных tasks.json запрещен`, код 1 |
